# DirectForge — Part 84

Dependency-free educational preference-optimization evidence laboratory **reconstructed** for Node.js Full Mastery Part 84. It demonstrates the mathematics and evidence flow around offline preference objectives; it does **not** download, train, fine-tune, or call external AI models.

## What it models

- chosen vs rejected preference pairs;
- log-probability margins;
- reference-policy-relative preference signals;
- DPO-style objective calculations;
- deterministic dataset validation;
- stable evidence generation for educational comparison.

## Commands

```bash
npm test
npm run demo
npm run verify
```

The reconstructed regression suite preserves the historical target of **12 passing tests**.

## Safety and production boundary

The project is a local mathematical/engineering laboratory, not a model-training service. Real preference optimization additionally requires carefully governed datasets, privacy review, evaluation against bias and misuse risks, reproducible training infrastructure, model/version provenance, and deployment-specific safety controls.
