# Supplemental Projects

These projects are **new educational laboratories** added after the numbered Node.js Full Mastery series was completed. They are not presented as recovered Part 1–125 companion archives.

| Project | Focus |
|---|---|
| `bounded-job-queue` | bounded queues, retries, dead letters, idempotent IDs |
| `ttl-lru-cache` | TTL, LRU eviction, cache metrics |
| `token-bucket-gateway` | rate limiting and retry-after math |
| `idempotent-api-kernel` | idempotency keys and request fingerprints |
| `stream-backpressure-lab` | streams, line bounds, pipeline error propagation |
| `service-health-kernel` | liveness, readiness, dependency gates, draining |
| `event-consumer-kernel` | partition offsets, duplicates, poison events |
| `config-redaction-kit` | config validation and safe diagnostics |
| `request-context-lab` | AsyncLocalStorage, correlation IDs, async context isolation |
| `graceful-shutdown-coordinator` | ordered cleanup, idempotent shutdown, lifecycle evidence |
| `circuit-breaker-kernel` | closed/open/half-open state, cooldown and recovery probes |
| `bounded-concurrency-pool` | bounded parallelism, stable results, peak concurrency evidence |

Every lab is dependency-free, requires Node.js 20+, includes `npm test`, `npm run demo`, `npm run verify`, architecture documentation, and mastery challenges, and is clearly separated from historical Part 1–125 provenance.

Repository policy also keeps supplemental project documentation free of permanent X/Twitter profile URLs and keeps supplemental project directories free of native promotional image assets.
