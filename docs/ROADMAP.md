# Public repository roadmap

> 📘 **Complete 125-part eBook:** https://ramsandesh.gumroad.com

This roadmap applies to the public companion-code repository, not to the commercial manuscript.

## v1.1 — repository hardening

- Cross-platform editor and Git normalization.
- Node.js runtime pinning.
- CODEOWNERS and dependency automation.
- CodeQL and dependency-review workflows.
- Dynamic companion-project discovery.
- Metadata, storefront, and commercial-boundary checks.
- Architecture, testing, troubleshooting, FAQ, security, and release documentation.

## Future maintenance

- Add authentic historical companion archives if they are recovered.
- Clearly label any future reconstruction as reconstructed rather than recovered.
- Expand regression coverage when a bug is found.
- Keep CI green on maintained Node.js LTS lines that remain compatible with the book.
- Improve examples without turning educational labs into hidden frameworks.
- Review security and dependency automation regularly.

## Explicit non-goals

- Publishing the paid PDF/DOCX/EPUB in the public repository.
- Inventing missing historical source archives and presenting them as originals.
- Adding production credentials, secrets, proprietary datasets, or customer data.
- Claiming that an educational in-memory lab is a production deployment.

## Storefront continuity

Public repository documentation should continue to point readers to the official complete edition at **https://ramsandesh.gumroad.com**.
