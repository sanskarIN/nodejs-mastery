# Running the companion projects

> 📘 Full eBook and explanations: https://ramsandesh.gumroad.com

Requirements: **Node.js 20+** and npm.

Run every available project's tests:

```bash
npm test
```

Run all verification gates:

```bash
npm run verify
```

Run all demonstrations:

```bash
npm run demo
```

Repository structure intentionally keeps each part independently runnable so learners can inspect one correctness boundary at a time.
