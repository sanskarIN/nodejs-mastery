# Privacy and data handling

> 📘 **Complete Node.js Full Mastery eBook:** https://ramsandesh.gumroad.com

This public companion repository is designed for local educational execution and does not require production customer data.

## Repository code

The currently published labs should use deterministic, synthetic, or developer-provided test data. They should not embed customer records, production database exports, access tokens, authentication cookies, private API payloads, or other sensitive operational data.

## Telemetry

The repository does not require an analytics account or telemetry service to run its companion projects. If a future example demonstrates telemetry concepts, the example should default to local/in-memory evidence unless an external integration is clearly optional and documented.

## Issues and pull requests

GitHub issues and pull requests are public. Do not include:

- passwords, tokens, certificates, private keys, or secrets;
- personal customer information;
- confidential business records;
- private paid-book files;
- vulnerability details that should follow the private security-reporting process.

## Logs and examples

Tests and demos should avoid printing secret-like values or personally identifying datasets. Examples should prefer synthetic identifiers such as `user-1`, `tenant-a`, or deterministic fixture values.

## Commercial storefront

Purchases and storefront account data are handled by the commercial platform according to its own terms and policies; those systems are separate from this GitHub companion repository.
