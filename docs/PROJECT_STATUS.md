## Provenance rules

- **Recovered** — traceable to an original series artifact.
- **Reconstructed** — rebuilt from historical series evidence because an original archive could not be retrieved.
- **Unavailable** — not enough authentic source/provenance exists to publish a trustworthy public lab.

See [`RECOVERY_POLICY.md`](RECOVERY_POLICY.md) for the acceptance process.

If additional authentic companion archives are recovered later, they can be added with provenance noted here. The root project-discovery code will include them automatically once they follow the `projects/part-NNN` standard.
