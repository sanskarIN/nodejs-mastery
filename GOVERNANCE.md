## Decision principles

Repository decisions prioritize, in order:

1. correctness and reproducible evidence;
2. safety and security boundaries;
3. clarity for learners;
4. preservation of authentic project provenance;
5. maintainability across supported Node.js versions;
6. a clear separation between MIT-licensed public code and the proprietary commercial eBook.

## Contributions

Pull requests are welcome when they improve public companion code, tests, documentation, or tooling. The maintainer may request additional tests, smaller changes, provenance evidence, or scope reduction before accepting a change.

## Historical project recovery

A recovered archive should be labeled **recovered** only when its source can be traced to the original series artifacts. A newly authored replacement must be labeled **reconstructed**. Missing material must not be silently fabricated and presented as original.
