```bash
git config user.name "Sanskar"
```

## Before opening a pull request

1. Use Node.js 20 or newer.
2. Run `npm test`.
3. Run `npm run verify`.
4. Run `npm run check`.
5. Do not commit the paid PDF, DOCX, EPUB, answer keys, source manuscripts, or commercial publishing package.
6. Keep examples educational, safe, deterministic, and reviewable.
